# College Event and Club Management System (CECMS)

A web-based application designed to simplify college club and event management. Students can explore clubs, register for events, and receive notifications, while coordinators and administrators manage events and system activities.

## Features

- Student registration and authentication
- Browse and join college clubs
- View and register for events
- Notifications and event updates
- Event and registration management
- Role-based access for students, coordinators, and administrators

## Technology Stack

- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JWT and bcryptjs

## Getting Started

### Prerequisites
- Node.js and npm
- MySQL Server
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/diyaskamath/College-Event-and-Club-Management-System.git
   ```

2. Navigate to the backend directory and install dependencies:

   ```bash
   cd backend
   npm install
   ```

3. Create a `.env` file using `.env.example` and configure the database credentials.

4. Set up the database:

   ```bash
   npm run db:setup
   ```

5. Start the backend:

   ```bash
   npm run dev
   ```

6. Run backend tests using `npm test`.

*Note: Frontend setup instructions will be added once frontend integration is complete.*
